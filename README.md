# Network Level Attacks and Countermeasures

## Lab: Perform MAC Flooding using macof to Compromise the Security of Network Switches

---

## Objective

The objective of this lab is to perform a MAC flooding attack using the `macof` utility and observe its effects on network traffic using Wireshark.

---

## Background

A switch maintains a Content Addressable Memory (CAM) table that maps MAC addresses to switch ports. When the CAM table becomes full, the switch may begin forwarding traffic out of all ports, behaving similarly to a hub.

The `macof` tool, part of the dsniff suite, generates packets with random MAC and IP addresses to flood the CAM table. This can allow an attacker to observe network traffic that would otherwise not be visible.

### Step 4: Execute MAC Flooding Attack

Run the following command:

```bash

```

#### Parameter Explanation

| Option | Description |
|----------|-------------|
| `-i` | Specifies the network interface |
| `-n` | Specifies the number of packets to send |

The command begins flooding the network with packets containing random MAC and IP addresses.

## Results

The MAC flooding attack successfully generated packets with spoofed MAC and IP addresses. These packets were captured and analyzed using Wireshark.

The attack demonstrates how flooding a switch's CAM table can potentially cause the switch to operate like a hub, increasing the risk of network traffic interception.

---

## Countermeasures

To mitigate MAC flooding attacks, organizations should implement:

- Port Security
- Static MAC Address Assignments
- DHCP Snooping
- Dynamic ARP Inspection (DAI)
- Network Monitoring and IDS/IPS Solutions
- Storm Control Features

---



## Conclusion

In this lab, a MAC flooding attack was performed using the `macof` utility. Wireshark was used to capture and analyze the generated traffic. The exercise demonstrated how excessive MAC address generation can impact switch operations and potentially expose network traffic. Implementing switch security features such as port security can help protect against this type of attack.
